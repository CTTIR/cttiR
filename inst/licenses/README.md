# Upstream documentation notices

Source documentation indexed for retrieval retains its upstream license. The
catalog stores each source revision, original text, checksum, DESCRIPTION and
rights basis. Rendered vignette HTML/PDF and binary assets are metadata only.

The [complete notice index](upstream/README.md) covers the 62 exact source
identities in all 14 bundled catalog snapshots. Its manifest associates each
source with byte-preserved upstream notices and separately labelled standard
license terms. The cttiR MIT license applies to its original code; it does not
relicense upstream documentation. RColorBrewer's exact COPYING and required
acknowledgement are retained, including the discrepancy with its DESCRIPTION.

  `workflowr-LICENSE.txt`; the MIT terms are reproduced in the workflowr template's
  `PROVENANCE.md`.
- digest 0.6.39: GPL version 2 or later. The GPL version 2 text is in
  `digest-GPL-2.txt`. Upstream credits are preserved in the catalog DESCRIPTION.
  The R interface credits Dirk Eddelbuettel (2003–2025), Henrik Bengtsson
  (2009–2019), Hannes Muehleisen (2012–2019), Jim Hester (2014–2019),
  Kendon Bell (2019), Matthew de Queljoe (2019), and Bill Denney (2025).

These notices cover source-document retrieval. They do not constitute an
approval to include any source in training data or a model release; those have
separate source/example and redistribution reviews.
